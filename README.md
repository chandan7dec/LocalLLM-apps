## 🧩 Common Themes

All projects in this workspace share a core philosophy:

- **Local Inference**: Models run on your hardware via Ollama, llama.cpp, or local APIs
- **Zero Cloud Dependency**: No mandatory API keys or external services for core functionality
- **Privacy First**: Your data stays on your machine
- **Open Source**: Free to use, fork, and build upon
- **Real-World Utility**: Each project solves a practical problem end-to-end

---

## 🚀 Getting Started

Each project is self-contained with its own setup instructions. Clone the workspace and navigate to any project of interest:

```powershell
git clone https://github.com/47thtechcorner/LocalLLM.git
cd LocalLLM
```

Then follow the individual `README.md` inside each project folder for setup and run commands.
